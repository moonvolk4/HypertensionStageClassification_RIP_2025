# Разработка интернет-приложений (РИП) 2025
## Расчет стадии гипертонической болезни
Разработанное приложение позволит лечащим врачам создавать и формировать заявки на расчеты стадий гипертонической болезни для пациентов, а главным врачам завершать или отклонять данные заявки.
